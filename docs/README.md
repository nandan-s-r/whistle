## Product and design records

[Blueprint coverage](BLUEPRINT_ACCEPTANCE.md) tracks the original 31-page specification. [Ecosystem status](ECOSYSTEM_STATUS.md) records the expanded workflows and their remaining work.

The UIUX documents, [product assessment](PRODUCT_ASSESSMENT.md), [quality review](PRODUCT_QUALITY.md) and [original repository comparison](GITHUB_REFERENCE_REVIEW.md) explain earlier decisions. They are dated development records. Later changes may replace the behavior described in an older entry.

[Verification records](VERIFICATION.md) preserve test results, corrections and limitations. Use [current deployment](DEPLOYMENT.md) for today's hosted status. Screenshots referenced in older records are local development artifacts and are excluded from Git.

The original VC Scope name remains in the blueprint and compatibility identifiers. The product is called Whistle. The current palette is recorded in [Warm palette](WARM_PALETTE.md), and the current brand is described in [Brand and content](BRAND_AND_CONTENT.md).
